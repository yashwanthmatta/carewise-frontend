# Rules 2026-10-20.5: what changed since the clinical-review candidate (2026-10-20.2)

The protected tag `clinical-review-candidate-2026-10-20.2` is unchanged; this record does not
replace it. The live website and phone app now run rules `2026-10-20.5`. **None of these
changes are clinically validated yet.** The clinician should review them alongside the .2 pack.

## Changes

| Version | Change | Type | Threshold or wording changed? |
|---|---|---|---|
| .3 | Results far outside the lab's range are labelled "Far above / Far below the lab's range" (rule 3 was already calculated but only "High"/"Low" was shown). Not urgent. | Display of an existing rule | New label text |
| .3 | Summary groups vitamin B12 and folate separately, so folate is never named when it wasn't tested | Defect fix | Summary text |
| .4 | A test name in a heading or list never takes a different test's value from a later line ("Lipid panel and A1C" then "Total cholesterol 228" was read as A1C 228%) | Safety defect fix (extraction) | No |
| .5 | "Vitamin D, 25-hydroxy" with no result is no longer read as a vitamin D of 25 | Safety defect fix (extraction) | No |

Details: `docs/clinical-rules-for-review.md`. Tests: `scripts/eval/heading-values.mjs` (runs in CI).
