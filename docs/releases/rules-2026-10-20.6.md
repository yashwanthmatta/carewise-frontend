# Rules 2026-10-20.6: the "3" in "vitamin D3" is part of the name

The protected tag `clinical-review-candidate-2026-10-20.2` and the .5 review pack in
`docs/clinical-validation-2026-10-20.5/` are unchanged. **This change is not clinically
validated.** It needs the same clinician review as .3 to .5 before it counts as validated.

## The defect (found by the independent fix check, 2026-10-23)

Rules .5 stopped "Vitamin D, 25-hydroxy" with no result from being read as a vitamin D of 25.
The same kind of mistake still happened when the lab wrote the vitamin's form (D2, D3, D2+D3).
The digit in the name was read as the result:

| Report line | .5 read | .6 reads |
|---|---|---|
| `Vitamin D3 25 ng/mL 30-100 L` | 3 ng/mL | 25 ng/mL |
| `Vitamin D2+D3 (25-OH) 41 ng/mL 30-100` | 2 ng/mL (shown as low) | 41 ng/mL |
| `Vitamin D3, 25-hydroxy: 18.5 ng/mL` | 3 ng/mL | 18.5 ng/mL |
| `Vitamin D3` then `Pending` | 3 ng/mL (invented) | no value ("could not read the value") |
| `Vitamin D3 deficiency screen` then `Ferritin 45 ng/mL` | 3 ng/mL (invented) | no value |
| `25-OH Vitamin D2+D3` then `< 8 ng/mL` | 2 ng/mL | no value (the "<" result isn't read as a number) |

The worst case is a normal result such as 41 ng/mL shown as 2 ng/mL, "Needs attention".

## Change

| Version | Change | Type | Threshold or wording changed? |
|---|---|---|---|
| .6 | The vitamin D reader skips a D2/D3/D2+D3 suffix, and a result never starts right after a letter | Safety defect fix (extraction) | No |

Changed in the same way: website `script.js` and phone app `src/reportAnalysis.ts`, so both apps use the same rules.

## Effect on the 160 review cases

All 160 cases in `docs/clinical-validation-2026-10-20.5/validation-cases.csv` were run through the
.5 code (`main`) and the .6 code. Values, findings, risk level, urgent reasons and questions
were compared. **0 cases changed**, because none of them writes D2 or D3. Urgency changes: 0.
